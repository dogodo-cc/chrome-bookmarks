03 / 你可能想知道

一点小问答。

还想了解更多？
在 GitHub 聊聊 ↗

需要重新导入我的书签吗？+

不需要。插件直接读取浏览器现有书签，把文件夹展示为画布上的卡片。对书签的移动、重命名和删除，也会反映在浏览器书签中。

支持哪些浏览器？+

适用于 Chrome 和 Edge。点击页面上的安装按钮前往 Chrome 网上应用店；Edge 用户可通过同一商店安装扩展。

我的画布布局会保存吗？+

会。插件使用浏览器的同步存储保存卡片位置、大小和画布视角；同步存储不可用时，会回退到本地存储。跨设备同步取决于浏览器的同步设置和存储配额。

插件需要哪些权限？+

当前版本声明了 bookmarks、storage 和 contextMenus 权限，用于书签管理、设置保存和上下文菜单。书签图标会向 favicon.im 请求获取，你可以在 GitHub 查看完整源码。

在哪里查看操作指南或反馈问题？+

打开插件后，点击右上角的 💡 图标即可查看手势和鼠标操作指南。问题和建议可提交到 GitHub Issues ↗。
